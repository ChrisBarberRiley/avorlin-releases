# Avorlin for Mac — releases

Signed and notarised installers for the Avorlin desktop app.

**[Download the latest version](https://github.com/ChrisBarberRiley/avorlin-releases/releases/latest/download/avorlin-mac.dmg)** — open the DMG and drag Avorlin into Applications. The app keeps itself up to date from here.

The app's source code is private; this repository only hosts release builds.
